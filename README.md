# School Local Platform

A frontend-only desktop workspace for school staff. This repository is the standalone UI build; it is intentionally separate from the Laravel demo/reference repository.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

## Current scope

- Shared staff sidebar navigation
- Four role previews: Director, Administrative Manager, Pedagogical Manager, Finance & Logistics Manager
- Role-based navigation visibility
- Expandable navigation groups, active item state, search, and collapsed sidebar
- Responsive sidebar behavior

All data and interactions are local demo state. There is no backend, database, authentication, or API integration.

## Build

```bash
npm run build
```
